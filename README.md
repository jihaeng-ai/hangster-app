# 노무 현황 관리표 — 노무 Risk, Low Return

병원 노사협력팀 담당자가 엑셀·PDF 자료를 올리면, 경영진이 노무 현황을 **버튼형 대시보드**와 **AI에게 말로 묻기**로 빠르게 확인하는 웹 서비스입니다.

> 🌐 **배포 주소:** https://hangster-app.vercel.app (로그인 필요 · 배포본은 미리 넣은 샘플 파일만 보여주고 업로드는 막혀 있습니다)
>
> ⚠️ 이 저장소의 데이터는 모두 **실습용 가짜(샘플) 데이터**입니다. 실제 병원 직원 정보는 들어 있지 않습니다.

## 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 핵심 지표 대시보드 | 첫 화면에 임금 인상률·의료원 인력·노조 전임간부·노조 차량 지원 4개 지표를 숫자 카드로 보여주고, 카드를 누르면 차트와 변화 설명을 봅니다 |
| 변화 설명 | 외부 AI 없이 서버가 정해진 문장 틀에 숫자를 채워 "전년 대비 증감, 최고·최저 시점"을 3문장 이내로 설명합니다 |
| 전임간부 조직도 | 연도 → 기간을 고르면 그 기간의 전임간부를 사람 픽토그램 조직도(유급·무급)로 보여줍니다 |
| AI에게 묻기 | "올해 직종별 인원은?"처럼 물으면 올라온 데이터로만 3문장 답과 차트를 보여줍니다. AI에는 **질문 문장만** 보내고 데이터·숫자는 보내지 않습니다 |
| 파일 관리 (담당자) | 엑셀·PDF 올리기, 같은 기간 교체, 삭제 (로컬 실행에서만 — 배포본은 샘플만 보여줌) |
| 로그인 | 담당자·경영진 계정 2개. 로그인하지 않으면 어떤 화면도 볼 수 없습니다 |

## 안전장치

- 원본에 없는 숫자는 만들지 않고 **"데이터 없음"**으로 표시하며, 모든 차트에 기준일·출처 파일(PDF는 쪽 번호)을 적습니다.
- AI 질문은 사번·주민번호처럼 보이는 숫자, 개인을 특정하는 질문, 전임간부 명단 요청을 **AI로 보내기 전에** 막습니다. 노무·법률 판단은 하지 않습니다.
- AI 질문 횟수 제한(한 사람 1분 10번, 하루 전체 300번), 보안 헤더, 검색엔진 수집 금지.
- 비밀값(API 키·계정 비밀번호)은 `.env`와 Vercel 환경변수에만 두고, 저장소에는 올리지 않습니다.

## 기술

- **Next.js 16** (App Router) + React 19 + TypeScript + Tailwind CSS 4 — Vercel 배포
- 엑셀 `exceljs` · PDF `unpdf` · 차트 `recharts` · 로그인 `iron-session` · 입력 검증 `zod` · AI 질문 해석 `openai`(gpt-4.1-mini)

## 내 PC에서 실행하기

1. 프로젝트 폴더에 `.env` 파일을 만들고 아래 값을 넣습니다 (값은 직접 정합니다).

   ```
   AUTH_SECRET=32자 이상의 무작위 문자열
   AUTH_MANAGER_ID=담당자 아이디
   AUTH_MANAGER_PASSWORD=담당자 비밀번호
   AUTH_EXEC_ID=경영진 아이디
   AUTH_EXEC_PASSWORD=경영진 비밀번호
   OPENAI_API_KEY=OpenAI API 키
   OPENAI_MODEL=gpt-4.1-mini
   ```

2. 설치하고 실행합니다.

   ```
   npm install
   npm run dev
   ```

3. 브라우저에서 http://localhost:3000 으로 접속해 로그인합니다.

## 확인 명령

| 명령 | 확인하는 것 |
|---|---|
| `npm run lint` / `npm run build` | 코드 오류 |
| `npm run samples:check` | 샘플 파일을 읽은 값이 원본과 같은지 |
| `npm run check:guard` | 사번·개인·명단 질문 차단 |
| `npm run check:describe` | 변화 설명 문장 규칙 |
| `npm run check:gaps` | 데이터 교체·기간 처리 규칙 |
| `npm run check:ratelimit` | AI 질문 횟수 제한 |
| `npm run check:success -- <주소>` | 대표 질문 10개·화면 속도 (실행 중인 서버에 요청) |
